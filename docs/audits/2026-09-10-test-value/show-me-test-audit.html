Scope, method and limits

Audited UltraModern commit 4092c606b0. Later upstream work already merged into the fork was subtracted; inherited and mechanical changes were excluded. Source links point to that exact commit.

File tiers cover the fork changes only. A T3 verdict in an existing Modern.js file does not mean deleting the inherited tests. Read the stated scope and preserve the named survivors.

The report includes 2,010 assertion/scenario findings. They include grouped scenarios and individual assertions, not a count of executed tests. Validation combined source inspection, targeted Node tests and isolated adversarial probes. The full monorepo/browser fleet and Tractor acceptance were not run.

Useful counts and strings can express a real contract: bounded retries, unique route IDs, one wire header, emitted code, or preserved user files. The deletion target is weak or duplicated proof, not a particular assertion syntax.
